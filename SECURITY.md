# Security Policy

## Supported Versions

Only the latest published minor release of `pkcore` receives security fixes.

| Version | Supported |
| ------- | --------- |
| 0.15.x  | Yes       |
| < 0.15  | No        |

## Reporting a Vulnerability

Please do **not** open a public issue for a security problem.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/ImperialBower/pkcore/security/advisories/new).

Include what you can of:

- the affected version and feature flags,
- a minimal reproduction,
- the impact you expect (panic, wrong result, resource exhaustion, …).

You should get a first reply within 7 days. Once a fix is ready, it ships in a
patch release and the advisory is published with credit to the reporter,
unless you ask to stay anonymous.
